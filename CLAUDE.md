# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

```bash
npm run dev          # Start dev server at http://localhost:3000
npm run build        # Build for production
npm run generate     # Static site generation
npm run preview      # Preview production build

npm run test         # Run all tests (unit + nuxt + e2e)
npm run test:unit    # Vitest unit tests (test/unit/)
npm run test:nuxt    # Vitest Nuxt integration tests (test/nuxt/)
npm run test:e2e     # Playwright e2e tests (test/e2e/)
npm run test:watch   # Vitest in watch mode
npm run test:coverage # Coverage report
```

ESLint runs via `npx eslint .` using the flat config generated by `@nuxt/eslint`.

## Architecture

This is a **Nuxt 4** portfolio site powered by `@nuxt/content` v3 as the CMS layer.

**Content routing**: Content pages are served under `/thoughts/` via [app/pages/thoughts/[...slug].vue](app/pages/thoughts/[...slug].vue). It queries the `content` collection by path and renders with `<ContentRenderer>`. Adding a new thought/post means creating a Markdown file in `content/` — no page file needed. The root `/` is a standalone [app/pages/index.vue](app/pages/index.vue).

**Content collection**: Defined in [content.config.ts](content.config.ts) as a `page` type collection covering all files in `content/`. This enables `queryCollection('content')` in components.

**Vue components in Markdown**: MDC syntax (`::component-name::`) embeds Vue components directly into Markdown. Example usage is in [content/index.md](content/index.md) with `Alert` and `Counter`.

**UI components**: `nuxt-headlessui` is installed with prefix `Ui`, so headlessui primitives are used as `<UiDialog>`, `<UiListbox>`, etc. Custom components live in `app/components/`.

**Styling**: Tailwind CSS v4 (via `@tailwindcss/vite`). Global styles and design tokens are in [app/assets/css/main.css](app/assets/css/main.css).

**Design system — Neobrutalist**: The aesthetic is defined by thick black borders (`border-2 border-border`), solid offset shadows (no blur), a warm off-white background, and `#d35400` as the primary accent. Key custom tokens:

| Token | Value | Tailwind utility |
|---|---|---|
| `--color-main` | `#d35400` (burnt orange) | `bg-main`, `text-main` |
| `--color-main-foreground` | `#fff` | `text-main-foreground` |
| `--color-background` | `#fdf6ec` (warm off-white) | `bg-background` |
| `--color-surface` | `#ffffff` | `bg-surface` |
| `--color-border` | `#000` | `border-border` |
| `--shadow-brutal` | `4px 4px 0 0 #000` | `shadow-brutal` |
| `--shadow-brutal-sm` | `2px 2px 0 0 #000` | `shadow-brutal-sm` |
| `--shadow-brutal-lg` | `6px 6px 0 0 #000` | `shadow-brutal-lg` |
| `--radius-base` | `4px` | `rounded-base` |

A typical neobrutalist element uses `border-2 border-border rounded-base shadow-brutal`.

**Testing structure**: Three separate projects in vitest:
- `test/unit/` — plain Node environment
- `test/nuxt/` — full Nuxt environment via `@nuxt/test-utils`
- `test/e2e/` — Playwright, Chromium only

**TypeScript**: `tsconfig.json` delegates entirely to Nuxt's auto-generated configs in `.nuxt/`.
