# VANHERK Portfolio

## Getting started

**Setting up your local development environment:**
```bash
$ nvm use 22
$ npm install
$ npm run dev
``` 

**Building for production:**
```bash
$ nvm use 22
$ npm install
$ npm run build
$ node --env-file .env .output/server/index.js
```

## Tech stack
This project uses Vue.js and Nuxt.js
